# Real-Time Traffic Analysis

This repository contains a real-time traffic analysis application built using Python and Streamlit.

## Features
- Real-time traffic data visualization.
- Easy-to-use interface for monitoring traffic patterns.

## Requirements
- Python 3.7 or higher
- Streamlit library

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/real-time-analisa-lalu-lintas.git
    ```
2. Navigate to the project directory:
    ```bash
    cd real-time-analisa-lalu-lintas
    ```
3. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Running the Application
To run the application, use the following command:
```bash
streamlit run app.py
```
